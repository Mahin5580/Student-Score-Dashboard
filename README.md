# Student Performance Analysis 📊

Data analysis and visualization project using Microsoft Excel to identify 
factors that influence student exam performance across 200 students.

## Overview
This project analyzes a 200-student dataset to determine which factors — 
study hours, attendance, and sleep time — have the most significant impact 
on final exam scores. Findings are presented through an interactive Excel 
dashboard with pivot tables, charts, and scatter plots.

## Key Findings
- **Study Hours** have a strong positive correlation with final scores 
  (avg score rises from 26.8 at 1-2 hrs to 43.1 at 11-12 hrs)
- **Attendance** showed minimal impact on final exam performance
- **Sleep Time** shows a moderate positive relationship with scores
- Students averaging 8+ study hours consistently outperform lower-hour peers

## Tools Used
- Microsoft Excel
  - Pivot Tables
  - KPI Dashboard
  - Bar Charts & Scatter Plots
  - Grouped Averages

## Dataset
- 200 student records
- Features: Attendance %, Study Hours, Sleep Time, Final Score
